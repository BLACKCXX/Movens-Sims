## 已知限制与物理结果

视觉复核看过五条真实/优化前/优化后总览。布局和外轮廓改善明显；源苹果纹理偏红，真实苹果的黄色区域未被重建；布面皱褶、桌面远缘和盘子内部明暗/形状仍不匹配。因此全部保留 `visual_qualified=false`，不会把数值轮廓通过当作完整场景合格。

盘子尺度逐条固定为源 CAD 的名义尺度（站点直径约0.182m，网格外径约0.185m），不是实测。每条各自拟合相机、苹果布局与额外尺度；源 CAD 只是形状先验，没有宣称五条是同一实物。FOV 69° 是继承的针孔先验，未独立标定。桌面尺度/外延只解释可见布面覆盖，部分参数触及范围上界，隐藏尺寸仍不确定。

本轮未用质量、摩擦或接触软硬参数追求图像拟合。源软层有已存在的形变；显示网格冻结该状态，完整物理副本仍保留自由节点。原盘子为固定体，不能验证其自由静置。

## API 与预算

数值预算每条最多600次候选评价；episode 1、2达到预算，保存最佳有效数值候选，未无限迭代。拟合耗时与各阶段墙钟见 fit_summary 和 receipts。已额外保存保守恢复计数，拒绝候选与中断不会重新获得预算。

官方 GPT 图像与结构化输出已真实运行。v1 发生一次 needs_review 搭配非空 updates 的语义错误，本地拒绝且保留响应。v2 加入明确的一致性规则，在前两条检查后保持 prompt、schema 和模型冻结，后三条均契约通过；五条 v2 全部 API 验证。后置复核只读，不修改已经达到预算的布局，也没有伪造候选改善。

所有上传图像都按请求参数恢复/归档，PNG SHA256 与16轮请求中的48张图像逐张一致（包含开发后的两版正式复核）；v2 图像在请求时直接保存。API key 不在任何归档内容内。模型ID、请求哈希、原始响应、用量、结构化验证及候选接受/回退均保留。
